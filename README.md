# Apprenticeship Data Pipeline Explorer

[![CI](https://github.com/fahim-ash123/apprenticeship-data-pipeline-explorer/actions/workflows/ci.yml/badge.svg)](https://github.com/fahim-ash123/apprenticeship-data-pipeline-explorer/actions/workflows/ci.yml)

A Python data product that retrieves Department for Education apprenticeship statistics from the Explore Education Statistics API and prepares them for analysis.

**Status:** in development.

**Python version:** 3.13.

## The report

The latest report is published at https://fahim-ash123.github.io/apprenticeship-data-pipeline-explorer/

It is rebuilt and published automatically every time a change is merged into `main`, and only after the tests and lint checks in CI have passed.
